# Python OOP: Inheritance & Encapsulation

Ushbu loyiha Python dasturlash tilida **Obyektga Yo'naltirilgan Dasturlash (OOP)** asoslarini o'rganish jarayonida yaratildi. 

## O'rganilgan mavzular:

1. **Classes & Objects (Sinflar va Obyektlar):** Real dunyo obyektlarini kodga ko'chirish.
2. **Inheritance (Vorislik):** `Foydalanuvchi` (Ota) klassidan `Admin` (Bola) klassiga xususiyatlarni o'tkazish.
3. **Encapsulation (Enkapsulyatsiya):** Maxfiy ma'lumotlarni (masalan: `__parol`) tashqi ruxsatsiz kirishdan himoyalash.
4. **Super() Method:** Ota klassning konstruktoriga murojaat qilish.

## Cyber Security uchun ahamiyati:
Kiberxavfsizlik yo'nalishida ma'lumotlarni yashirish (Private attributes) va tizim foydalanuvchilari iyerarxiyasini yaratishda ushbu bilimlar juda muhim hisoblanadi.
